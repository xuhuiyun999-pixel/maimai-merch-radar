# 麦麦周边雷达

用项目自带的只读查询助手获取真实信息，再回答用户。不能凭记忆填充库存、补货、资格或活动截止时间。

## 定位与运行

这个技能随完整项目分发；项目根目录是本文件所在目录向上两级，即包含 `pyproject.toml` 的目录。源码安装与依赖步骤见项目根目录 `README.md`。单独复制本 SKILL.md 不包含可运行助手。

在 Windows 上，将项目根目录记作 ROOT，使用：

```text
"ROOT\.venv\Scripts\python.exe" -m maimai_radar.cli query
```

ROOT 是定位说明，不是固定字符串；执行时使用实际绝对路径，并按当前 shell 的规则引用。PowerShell 调用带引号的程序路径时前置 `&`。其他系统使用该项目虚拟环境中的 Python。先检查本次命令的退出码及报告的查询时间，确认报告已由本次执行更新，再读取 `ROOT/output/radar.json` 的 `queries` 与 `cards`，将 `ROOT/output/radar.html` 链接交给用户。命令非零或报告未更新时必须说明本次失败，不把旧文件当作新的成功结果。

如果未配置凭据，提示用户在自己电脑上运行 `configure` 子命令。该命令隐藏输入并保存到项目根目录的私密 `.env`。不要读取、复述或要求用户在聊天中粘贴 Token。不要把凭据写入技能、公开配置或报告。

## 如何回答

- 先说明查询时间和成功来源，再简要列出相关周边活动线索、商品条件和原始说明。
- `queries` 中失败、缺参数或暂不支持的来源，必须单独说明；不能称为没有商品或活动。
- `coverage=unknown/partial` 表示没有确认完整或只返回部分数据。不要说“全部周边”“全网活动”。
- 活动线索按标题与内容的关键词归类，可能有误收与遗漏。其他活动也保留在报告中。
- 日历展示日期不等于完整活动期限；同一活动可能合并多个展示日期。原文描述有明确参与条件时可以引用事实，但不扩展成库存或资格保证。
- `phase=已过接口展示期限` 的商品属于历史返回记录。提醒用户不能据此认定现在可兑换；不把其他条目默认视为可兑换。
- 缺失字段解释为“接口未提供”；保留零积分和零现金数值的含义，不把它们当缺失值。
- 只有明确的 HTTP(S) 来源才链接；App 内部跳转地址不改写成猜测的网页链接。
- `demo=true` 或运行 `demo` 子命令得到的内容必须称为“虚构样例”，不能算真实接入。

## 商品详情

当用户从真实列表中选定商品后，先运行 `discover` 确认服务当时的输入结构。当前发现的详情输入为整数 `spuId`；商品编号可从报告的 `item_id` 取得。把用户选中的编号写入本地私密 JSON 参数文件，再运行：

```text
"ROOT\.venv\Scripts\python.exe" -m maimai_radar.cli query --tool mall-product-detail --arguments-file "ROOT\private\detail-arguments.json"
```

详情报告位于 `ROOT/output/details/radar.html`，结构化结果位于同目录的 `radar.json`，不会覆盖总览。读取本次详情目录中的状态和查询时间，不把总览目录当详情结果。

历史样本已实际验证返回“商品已下架”（610403）的失败路径；遇到该状态照实说明，不反复重试。成功详情资料的结构仍待有可查询商品时验证；若 CLI 返回 `unsupported`，明确告诉用户详情资料暂未适配，不能把未知结构解释为空。开发者需要验证实际结构后再增补适配与测试。不要为展示效果而自动挑商品逐项查询。

## 业务边界

助手仅允许商城列表、商品详情与活动日历三个查询工具。不调用其他工具，不自动发送通知或替用户参与活动。比赛回车键和徽章不预设为商城可兑商品，查询不到不代表比赛奖品不存在。
